# AI Task Manager

Task manager con inteligencia artificial construido con React, Node.js y Groq AI.

## 🚀 Tecnologías

- **Frontend:** React + Vite + TailwindCSS
- **Backend:** Node.js + Express
- **Base de datos:** MongoDB Atlas
- **IA:** Groq AI (Llama 3)

## ✨ Features

- Crear, editar y eliminar tareas
- Marcar tareas como completadas
- Prioridades (alta, media, baja)
- Sugerencias inteligentes con IA
- Filtro por alta prioridad

## ⚙️ Instalación

1. Cloná el repositorio
2. Configurá las variables de entorno en `server/.env` (ver `server/.env.example`)
3. Instalá dependencias:

\```bash
cd server && npm install
cd ../client && npm install
\```

4. Iniciá el proyecto:

\```bash
# Backend
cd server && npm run dev

# Frontend
cd client && npm run dev
\```
